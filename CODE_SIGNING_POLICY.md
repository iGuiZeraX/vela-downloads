# Code signing policy

O projeto está preparando uma solicitação de assinatura gratuita para código aberto. Não há aprovação, certificado emitido ou assinatura fornecida pela SignPath Foundation neste momento.

Responsável pelo repositório, revisão e aprovação de releases: [iGuiZeraX](https://github.com/iGuiZeraX).

Somente versões verificadas a partir do código deste repositório devem ser submetidas à assinatura, com revisão manual dos artefatos, dependências e permissões. Não serão assinados componentes de terceiros como se fossem de autoria própria; o formato e a cobertura do pacote Electron precisam da análise do provedor.

O responsável deve usar autenticação de dois fatores, controlar os aprovadores e validar as assinaturas e os hashes dos arquivos distribuídos. Dados privados, chaves e tokens de assinatura não entram no repositório.

Se o projeto for aprovado, esta política deve ser atualizada com os papéis definitivos e a atribuição exata exigida pelo provedor. A presente proposta não declara um vínculo já existente.

Privacidade: o Vela não transmite telemetria. Solicitações de download são realizadas apenas para links adicionados pelo usuário; histórico e código de conexão permanecem no computador.
