DO NAVEGADOR PARA O VELA

Uma conexão mais direta.

Adicione a extensão para enviar seus downloads do Chrome para cá.

  1. 1
    Abra as extensões do Chrome

    Digite chrome://extensions na barra de endereço e ative o Modo do desenvolvedor.

  2. 2
    Carregue a extensão do Vela

    Clique em Carregar sem compactação e selecione a pasta abaixo.

  3. 3
    Conecte com seu código local

    Copie o código e cole no popup da extensão. Depois, habilite Captura automática se quiser enviar os downloads do Chrome ao Vela.

A captura automática é opcional. Mantenha o Vela aberto para receber downloads.
